# Assetly v1 마감 체크리스트

기준일: 2026-10-18

## 범위

포트폴리오용 v1의 핵심 사용자 흐름을 마무리한다. 실제 서버 생성·배포·과금 자원 변경은 이번 범위에서 제외한다. 점검·대여·첨부 이미지 등 v1.1 기능도 추가하지 않는다.

## 비배포 검증 완료

- [x] 회원가입·로그인·조직 온보딩·로그아웃과 조직 전환.
- [x] 실제 API를 통한 자산 등록·수정·비활성화와 저장 결과 재조회.
- [x] QR 로그인 복귀, 모바일 현장 수정과 SVG 다운로드.
- [x] 대시보드·자산·기준 정보·멤버·이력 조회 실패를 빈 데이터와 구분.
- [x] 실패한 조회를 새로고침 없이 재시도.
- [x] 선택 항목 조회 실패·로딩 중 자산 저장 차단, 재시도 시 입력 유지.
- [x] 자산번호·자산명 공백 입력 차단과 저장 중 폼 변경 제한.
- [x] 다른 조직으로 전환할 때 이전 자산 상세·폼 제거.
- [x] 작업 도중 401 응답 발생 시 토큰 정리와 원래 경로를 포함한 로그인 이동.
- [x] 자산 이력 20개 초과 시 이전 기록 조회.
- [x] 검색 결과가 없을 때 조건 초기화.
- [x] 조회 전용 역할의 멤버 관리 폼 노출 차단. 실제 권한은 서버에서 별도 검사.
- [x] 360·768·1024·1440px에서 대시보드, 자산 목록·등록·상세, 조직 이력, 기준 정보, 멤버, 설정, QR 경로의 페이지 폭 점검.
- [x] 긴 자산명·자산번호 줄바꿈, 비활성화 버튼 폭과 QR 도구 배치 확인.
- [x] 키보드 포커스 표시와 현재 내비게이션의 `aria-current` 적용.
- [x] 클립보드 실패 시 오류 안내. 지원하지 않는 브라우저에서 무조건 복사 성공으로 표시하지 않음.
- [x] ESLint와 production build 성공.
- [x] 로컬 H2·production 프론트엔드 Playwright: 27개 통과, 5개 프로젝트 조건부 제외.

화면 폭 검사는 문서 가로 넘침과 버튼 글자 영역을 자동 확인한다. 표와 모바일 내비게이션 내부의 의도된 가로 스크롤은 허용한다. 자산 상세 스크린샷은 `frontend/test-results`에 생성하며 Git에 커밋하지 않는다. 전수 접근성 감사나 모든 브라우저의 호환성을 보증하는 결과는 아니다.

## 확인된 검증 명령

프로젝트 루트에서 각각의 경로로 이동해 실행한다. 브라우저 테스트에는 로컬·테스트용 서버가 실행 중이어야 한다.

```powershell
cd frontend
npm run lint
npm run build
npm run test:e2e
```

테스트는 연결한 DB에 계정과 조직을 생성한다. 운영 환경에 연결하지 않는다. 로컬 `local` 프로필 H2의 테스트 데이터는 백엔드 재시작으로 초기화한다. PostgreSQL 데이터를 테스트 정리를 이유로 임의 삭제하지 않는다.

## 배포 환경이 정해진 뒤

- [ ] 무료 한도·기존 자원 사용량·ARM 이미지 호환성과 실제 배포 사양 확인.
- [ ] 공개 주소, HTTPS와 방화벽 적용. 운영 비밀값과 SSH 접근 관리.
- [ ] 실제 주소로 생성되는 QR과 로그인 복귀 확인.
- [ ] 운영 정기 백업, 외부 사본과 실패 알림 구성.
- [ ] 외부 사본 복원 후 별도 앱 연결, 운영 전환·롤백 리허설.
- [ ] 서버 재시작, 로그 확인·디스크 용량 점검과 장애 대응.
- [ ] 공개 데모의 가용성·데이터 보관 한계와 민감정보 입력 금지 안내.
- [ ] 실제 서버에서 신규 계정 생성부터 QR 수정까지 최종 확인.

배포 관련 미완료를 기능 구현 완료와 혼동하지 않는다. 배포 여부를 결정하기 전에도 로컬 시연과 화면 검증은 가능하다.
